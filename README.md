# table-games-pds2

Projeto do Trabalho Prático Final de Programação e Desenvolvimento de Software II

O projeto tem como objetivo principal trabalhar os conceitos de Programação Orientada a Objetos além de aprofundar um pouco mais nas bibliotecas de C++

O projeto conta com interface gráfica desenvolvida com a biblioteca SFML para c++, por isso é necessário a instalação da mesma para compilação.
Os designs são encontrados em https://www.figma.com/proto/lQrKqwjaLGfGfv2qWTX41m/TP_PDS2?node-id=0-1&t=bxeRUmMhK6mcPvtT-1

A documentação foi gerada utilizando doxygen e comentários nos arquivos do projeto.
