Detailed Description

Implementa o jogo Lig4, derivado da classe base Game.

A classe Lig4 gerencia a lógica específica do jogo Lig4, incluindo a realização de jogadas, verificação de vencedores e execução de estratégias como o algoritmo Minimax.
