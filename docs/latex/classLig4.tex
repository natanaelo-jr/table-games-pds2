\doxysubsection{Detailed Description}
Implementa o jogo \doxylink{classLig4}{Lig4}, derivado da classe base \doxylink{classGame}{Game}. 

A classe \doxylink{classLig4}{Lig4} gerencia a lógica específica do jogo \doxylink{classLig4}{Lig4}, incluindo a realização de jogadas, verificação de vencedores e execução de estratégias como o algoritmo Minimax.
