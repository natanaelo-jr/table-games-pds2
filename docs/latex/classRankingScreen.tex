\doxysubsection{Detailed Description}
Classe responsável pela tela de ranking dos jogadores. 

A classe {\ttfamily \doxylink{classRankingScreen}{Ranking\+Screen}} exibe a lista de jogadores em ordem de classificação, permitindo navegar entre eles e visualizar suas estatísticas.
