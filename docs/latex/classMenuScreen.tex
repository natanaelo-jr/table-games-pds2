\doxysubsection{Detailed Description}
Classe responsável por representar a tela de menu principal. 

A classe {\ttfamily \doxylink{classMenuScreen}{Menu\+Screen}} herda da classe {\ttfamily \doxylink{classScreen}{Screen}} e implementa as funções necessárias para manipular os eventos, atualizar e renderizar a tela de menu principal do jogo.
