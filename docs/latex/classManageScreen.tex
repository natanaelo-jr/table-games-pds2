\doxysubsection{Detailed Description}
Classe responsável pela tela de gerenciamento de jogadores. 

A classe {\ttfamily \doxylink{classManageScreen}{Manage\+Screen}} permite ao usuário adicionar e remover jogadores, bem como manipular seus dados, como apelido e nome.
